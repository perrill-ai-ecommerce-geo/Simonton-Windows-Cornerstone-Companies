# Terminology (public-safe)

Use plain language first, then clarify terms:

- "Replacement windows": windows purchased to replace existing windows in a home.
- "Patio doors": exterior doors that open to a patio/deck (often sliding or multi-slide).
- "Warranty claim": a request for assistance based on product warranty coverage.
- "Replacement parts": components (e.g., hardware, screens) needed to repair an existing unit.
- "Order number": identifier on product labels used for registration/support workflows.
