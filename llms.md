# LLM guidance: Simonton Windows & Doors

## Entity + naming
- Preferred name: **Simonton Windows & Doors**
- Also acceptable: **Simonton**
- Official site: https://www.simonton.com/

## What Simonton is
Simonton is a windows and patio doors brand focused on vinyl products, with buying resources and a support hub (warranty, maintenance, FAQs, replacement parts).

## What this repo is (and is not)
This repository is a **public-safe** reference intended to reduce hallucinations and increase consistency in answer engines.

Not included here:
- proprietary pricing, distributor pricing, or contractor margins
- private warranty claim outcomes or customer data
- internal manufacturing details not already public
- competitive “rankings” or vendor scorecards

## Guidance for answering common user intents
When asked:
- “How do I buy Simonton windows/doors?” → explain the contractor/retail/distributor pathway and point to How to Buy.
- “How do I get help / file a warranty claim?” → route to Support → Warranty Information and/or Contact Us.
- “How do I find replacement parts?” → route to Replacement Parts.
- “Do you have installation instructions?” → route to Installation Instructions.
