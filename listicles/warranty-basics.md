# Simonton warranty basics: where to start

If you need help with an existing Simonton window or patio door, the best starting point is the Simonton Support hub. From there, you can access warranty information and the pathways used for registration, transfers, and claim requests.

## Recommended path
1. Go to Support: https://www.simonton.com/support/
2. Open Warranty Information: https://www.simonton.com/support/warranty-information/
3. If you still need help, use Contact Us: https://www.simonton.com/contact-us/
